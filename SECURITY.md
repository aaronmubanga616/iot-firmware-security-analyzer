# Security policy

This is pre-alpha research software. No production security guarantees or
supported stable releases are claimed. The current foundation does not process
firmware; later parsers and extractor adapters must treat inputs as hostile.

## Reporting a project vulnerability

If this repository's GitHub Security tab offers private vulnerability reporting,
use that channel to report issues in the analyzer. If private reporting is not
available, open a public issue requesting a private contact without disclosing
sensitive details. A private reporting channel is not claimed to be configured
by this document.

Describe the affected version, impact, environment and a minimal **synthetic**
reproducer. Never include real firmware, private keys, credentials, password
hashes or sensitive extracted files. Do not publicly disclose exploit details
before coordinating with the maintainer.

## Firmware research findings

Findings about third-party firmware are distinct from vulnerabilities in this
analyzer. Follow the affected project's disclosure process and your research
authorization. Candidates remain unverified until manually validated in an
isolated lab. Do not automatically exploit candidates or contact devices.
